# Robot skill source provenance

This package contains skill implementations extracted from
the project's research sources. Original notices and source headers are retained.
The repository's `reproduction/robotics-source.json`, `navigation-source.json`,
`interaction-robotics-source.json` and `hardware-source.json` record the source
identities and transformations. `bt_agent_robotics/hardware-source.json` is also
included in the installed package.

Project-authored software and associated documentation are licensed under
Apache-2.0; see LICENSE and LICENSE-SCOPE.md. Third-party code retains its own
terms. This code grant does not relicense scene data, recorded fixtures, robot
models, recordings or model weights. The recorded fixture under
`tests/reference/skills/fixtures/` keeps its original provenance field, which
names a path on the original workstation.
